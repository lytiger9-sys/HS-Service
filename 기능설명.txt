봇 이름: HS 종합봇

환영 기능
- 새 인원이 들어오면 지정한 채널에 임베드를 보내고 개인 dm으로 환영인사 및 안내문구를 보내주는 기능

- 변수명: {user}: 새로 들어온 유저 / {guild}: 서버명 / {totalmember}: 서버 총인원
    환영인사 메시지(임베드용):(웹사이트에서 설정)
    환영인사 메시지(dm용): (웹사이트에서 설정)
- dm 보내기 실패한 경우 웹사이트에서 지정한 채널로 오류 메시지 보내기


티켓 기능
- 관리자만 열고 닫을 수 있도록 하기
- 티켓 열리는 카테고리 위치 설정할 수 있도록 하기
- /저장 : 모달을 열고 제목과 내용을 입력할 수 있는 필드를 생성
- /저장내용 : 지금까지 저장한 내용을 한번에 보여주는 기능


서버 정보 확인 기능
- 서버 인원수, 서버 봇 수, 전체 인원 표시해주는 기능
- /공지: 웹사이트에 적어놓은 서버 안내사항을 볼 수 있는 기능
- /서버입장순서: 서버에 들어온 순서를 내림차순으로 정리
- 기타 서버의 모든 정보를 웹사이트에서 볼 수 있도록 하기


허니팟 기능
- 지정한 채널에 메시지를 보내면 서버 추방하는 기능
- 해당 채널 임베드에 현재까지 잡은 인원 수 표시해주는 기능


보안 기능
- 전체멘션을 보낸 유저가 있다면 타임아웃 적용(시간은 웹사이트에서 설정)
- 같은 메시지를 도배하는 유저가 있다면 타임아웃 적용
- 지정한 욕설(웹사이트)을 하는 유저가 있다면 타임아웃 적용
- 초대링크를 보내면 타임아웃 적용

기타 서버 관리 기능
- 해당 채널에 메시지를 남긴 사람에게 선택한 역할 지급
- 해당 채널의 메시지를 개수만큼(입력 안할 시 전체 다) 삭제해주는 기능
- 투표 기능: 투표할 임베드(관리자가 웹사이트에서 생성)를 만들고, 그에 대한 답변을 클릭을 통해 수집할 수 있는 기능.(마지막 항목은 자유 입력 가능하도록 하기)
- 임시 채널 만들기 기능: 간단한 명령어를 통해 음성채널을 만들어주는 기능
- 유저에게 적용되었던 제재 목록을 볼 수 있는 기능

웹사이트
- 여기있는 모든 로그 채널을 설정할 웹사이트 생성 및 웹사이트에서 임베드 생성 시 라이브 프리뷰 제공
- 흰/검 대비되는 색상을 통한 세련된 ui
- 각 봇별로 사이드탭 하나씩 만들어서 해당 봇 별로 설정할 수 있도록 하기
- 공용 모듈을 만들어 레이아웃이나 모달을 효과적으로 사용할 수 있도록 설정


기타 보안
- .env파일에 있는 서버 id가 아니라면 자동으로 해당 서버를 나가고, 작동하지 않는다.
