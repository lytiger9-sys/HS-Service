탭2: 관리자

1. 출퇴근 버튼을 만들어 관리자의 상태를 유저들이 확인할 수 있도록 한다.

2. 관리자(직원)별 상태를 유저가 한번에 보기 쉽도록 임베드를 만들어 게시할 수 있도록 한다(명령어는 /staff)


탭4: 티켓

1. 기존 명령어 티켓 오픈 및 티켓 클로스는 삭제

2. 티켓 관련한 로그 채널은 필요 없음

3. 유저가 버튼을 눌러 티켓을 열 수 있도록 함(티켓 임베드는 언제든 웹에서 편집할 수 있도록, discord component v2, live preview)

4. 티켓을 열 때 드롭다운 메뉴를 열어 어떤 카테고리로 티켓을 열지 설정할 수 있게 하고, 각 카테고리별로 어떤 서버 카테고리에 티켓 채널을 열지 설정할 수 있게 한다.
    또한 각 카테고리별로 티켓을 열때 정보를 수집할 모달의 질문을 설정할 수 있도록 한다.(필수, 필수아닌 질문 설정 가능하도록, 질문 내용도 직접 입력할 수 있도록)

5. 기존 명령어인 /save와 /savednotes는 모두 봇이 만든 티켓에서만 가능하도록 한다.

6. 티켓 닫기 관련
    티켓이 열릴때 저장된 정보(있다면)를 보내고, 티켓을 연 유저를 멘션한다.해당 임베드에 티켓 닫기 버튼을 달고 임베드를 전송한다(관리자만 닫을 수 있음)
    버튼을 누르면 다시 한 번 묻고, 삭제를 확정지으면 10초 후에 삭제한다. 티켓의 대화가 길어질것을 대비하여, 관리자가 !티켓닫기를 치는 순간, 첫 버튼을 누른것으로 간주하여 다시한번 묻고, 확정시 티켓을 10초 후 삭제한다.

탭 8. 허니팟

1. 허니팟 전용 로그 채널을 없애고, 허니팟으로 지정한 채널의 상단에 허니팟 로그 임베드를 소환하여 공지 및 상태를 전달한다.

탭 11. 로그

1. 기존 설정되어있는 로그채널들을 모두 삭제하고, 서버 로그를 보낼 채널을 지정할 수 있도록 한다.

2. 서버 로그에 보내질 항목에는
    (서버 이름변경, 메시지 수정/삭제, 카테고리 추가/수정/삭제, 채널 추가/수정/삭제, 서버 아이콘 변경, 서버 이름 변경, 유저 이름 변경)가 있고, 각각을 ON/OFF토글을 통해 보낼지 말지 설정할 수 있도록 한다.
